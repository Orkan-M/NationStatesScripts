# NationStates Scripts

A collection of custom **Tampermonkey** userscripts for **NationStates**, designed to improve the Trading Cards interface and make collection management and market analysis faster and more intuitive.

## 📦 Current Scripts

### 📊 NationStates Collection Manager

Enhances your Trading Card deck with intelligent collection analysis.

**Features**
- Highlights premium and high-value cards
- Identifies duplicate holdings
- Calculates portfolio statistics
- Suggests when to hold or sell based on Market Value and live bids
- Protects valuable cards from being sold too cheaply
- Displays a portfolio summary with useful collection metrics

---

### 🔎 NationStates Card Market Scout

Improves the live auction market by highlighting genuine buying opportunities.

**Features**
- Finds underpriced cards
- Highlights premium buying opportunities
- Detects junk-floor purchases
- Warns about overpriced listings
- Fades irrelevant auctions so genuine opportunities stand out
- Uses Ask, Bid and Market Value together to avoid misleading signals

---

## 🚀 Installation

1. Install the **Tampermonkey** browser extension.
2. Open this repository and select the script you want to install.
3. Click **Raw** in the top-right of the file.
4. Tampermonkey should automatically open an installation prompt.
5. Click **Install**.

Repeat these steps for any additional scripts you wish to use.

---

## 💻 Compatibility

These scripts are designed for the **NationStates Trading Cards** pages and are tested with **Tampermonkey** on modern Chromium-based browsers.
